🎮 HOW TO PLAY — VIEWER COMMANDS

Type one command in the active YouTube livestream chat. Include the exclamation mark.

!red
Support the Red Squad
!blue
Support the Blue Squad
!attack
Launch a battle attack
!defend
Raise team defenses
!power
Trigger a power-up
!build
Build a world structure
!forest
Add a neon forest
!castle
Build a fortress
!chaos
Trigger a random event

Commands are processed when the channel's active live chat is connected. A short per-viewer cooldown helps limit spam.
